Set up the admin panel

This runs once. Your GitHub token is encrypted with your password in this browser, and only the encrypted copy is saved to the site’s repository.

Site settings

Saved to _data/site.yml. Prices: write TBD (or leave empty) to show “Coming soon”. Store links: leave empty to show a “Coming soon” badge. If you change the tagline, description, Pro status or feature lists, every language shows your new English text until you update that language under Translations (the meta keys).

Policies

Saved to pages/privacy.md. Text like {{ s.product_name }} is filled in from Site settings when the site builds. Remember to update “Policies updated” in Site settings after a real change.

Translations

Saved to _data/i18n/es.yml. Keep placeholders such as %name%, %email%, %shortcut% and any HTML tags exactly as in English.

Other files

For anything not covered above: page templates, styles, the language list, and so on. Edits here are saved exactly as typed, so take care.
